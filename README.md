# Sigil & sigilOS — Security Posture Brief

A plain-language summary of how GrioCo approaches security for the Sigil language and sigilOS,
and what an internal red-team / blue-team review of the whole stack found at a high level. The
short version: the capability-based design is strong, the implementation is pre-1.0, and the
security guarantees currently describe the architecture more fully than the running system does;
the review has been turned into a prioritized remediation plan. The brief intentionally contains
no exploit details.

The full brief lives in [SECURITY.md](SECURITY.md).
